# Phase notes: Phase 2 (detail design; CDR)

- 2.1 Propeller shaft backward whirl (DYN-05): 12-element Timoshenko FE rotor (matched ROSS within 0.008%, TC18-23). Ip 15 / Id 7.5 kg m2. Phase 1 shaft 75/45 crossed 1x at 1,443-1,636 rpm. Fix: 120/100 mm thin tube, crossing 2,065-2,631 rpm (> 110% 1,870), DYN-05 ratio 1.67 (limit 2.5); needs seat stiffness >= 5e7 N/m; SFD dropped. Decision: 120/100 shaft (A).
- 2.2 PT output shaft: 0.55 m floating AISI 4340 tube 66 x 1.5 mm, 1.31 kg, diaphragm coupling each end; 1st bending critical 34,443 rpm (limit 26,640); fatigue SF 7.32; torque meter twist 0.40 deg, resolution 0.66% (CTL-01 2%); tunnel 15 mm insulation + 7.5 g/s buffer air: shaft <= 124.5 C in 700 C gas (limit 150). Max 0.60 m shaft length; PT rear roller bearing below skidding limit -> out-of-round outer ring.
- 2.3 Torsional: 14-DOF model (Lin & Parker planetary), modes >= 11.7% from 1P/4P/5P/10P and 1x/2x PT; 54 mm shaft mode 343 Hz sat in 330-370 Hz PT 1x band -> 66 mm (414 Hz). Sudden stoppage torque ~ 1/stop time, amplification ~2; >= 0.76 s stays within LD-01.
- 2.4 Gear rating ISO 6336:2019 Method B: S_H min 1.28 (sun-planet), S_F 1.65; superfinish all gears (Rz 0.8; ground only S_H 1.19); ring tips shortened 0.1 m; helix corrections; Monte Carlo K_gamma 1.32 (P99) vs 1.15; scuffing S_S >= 1.61 with 23699 at 132 C, 7808 no margin; LD-08 capacity 24,345 N m -> PT stop >= 0.22 s; first-stage gear web modes in band -> damping ring. Pyrowear 53 (AMS 6308) carburized gears, nitrided 32CrMoV13 ring. Decisions 1 (superfinish) and 2 (7808 only <= 105 C; later replaced by 23699 only in 3.3).
- 2.5 Bearings/shafts: all L10m > 12,000 h; planet bearing 14,500 h (full complement 18 x 7.5 x 56 mm, after 70 mm face, 8 mm rim - Decision 3, +3.5 kg); QJ1024 propeller 35,000 h; S_H 1.34, S_F 1.77; intermediate shaft 50/30, sun spline 56 mm crowned; Ti-6Al-4V retention tube 90/80 x 600 mm second load path (+3.6 kg, Decision 4) for SAF-01.
- 2.6 Accessory pads (generator, OSG, PCU, oil pump): min S_H 2.2; shear necks band bottom >= 3.6 x max rated torque; generator gear solid blank (mode 38 kHz), 6305 bearing 56,600 h, OSG 21/30 m2; generator raises first-stage gear root stress (S_F 2.61 -> 2.43); starter-generator stays on core AGB (ACC-01 interface).
- 2.7 Lubrication: losses 12.4 kW (98.71%, limit 13.6), heat into oil 14.9 kW (limit 18); superfinish -19% mesh loss; 32 jets 0.6-1.6 mm; need 23.5 L/min, pump 30.5 L/min, 2.4 kW; cooler 18 kW at 53 C, 0.72 kg/s air, 339 x 339 x 26 mm, 4.4 kg, oil back 100 C; Decision 5: electric fan on ground + ram air in flight (fan ~0.5 kW); tank 6.8 L.
- 2.8 Housing FE (MATLAB PDE Toolbox): first section failed (outer seat 3.3e7 < 5e7, fillets 226-252 MPa > 165); redesign conical nose 8 mm, A357-T6 10.94 kg; outer seat 9.47e7 (6.56e7 opened joint); R5 flange fillet 81 MPa (128 spring-supported) < 165; planet 3rd mode 6,063 Hz at 2x band edge; case shell modes in mesh bands -> response-based DYN-04 criterion. Decision 6: A357-T6 sand casting (vs WE43). Benchmarks: hole-in-plate, mesh convergence <0.3%.
- 2.9 CATIA V5 R19 parts built by VBScript from MATLAB parameter export (cx_export); true involute teeth; assembly with mesh phases; first A3 drawings of 6 parts.
- 2.10 Innovation WP = maintenance-driven design + HUMS (Decision 7 C): fault frequencies of all shafts, meshes, gear faults, 11 bearings; 23 pairs within 2% -> TSA; accelerometers at z 96 (case over ring) and z 442 (outer bearing boss) + first-stage case; inline ODM, borescope ports, modular RGB.
- 2.11 CDR: requirements v3 66 (STR-10 new, 12 changed); compliance met 29, partial 18, open 8, tbd 11, risk 0; DYN-05 closed. Phase 2 mass "about 90 kg" (not a CAD weighing).
