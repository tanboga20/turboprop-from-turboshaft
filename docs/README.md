# docs

**EN.** Figures and short notes of the project, in English and Turkish.

| Folder | Content |
| --- | --- |
| `figures/overview/` | Overview figures (engine cutaway and design scope, power path, tip speed, torque chain, phases and reviews, requirement status, compliance, test sequence, mass history), drawn by `make_figs.py`, and renders of the assembly and carrier drawings |
| `figures/phases/en`, `figures/phases/tr` | Figures of the analyses of each phase (prefixes `p0_` to `p3_`) |
| `figures/step36` … `figures/step312` | Figures of the Phase 3 analyses, written by the tools in `calc/` and `comparison/` |
| `notes/` | One page per phase with the main numbers and decisions |

**TR.** Projenin şekilleri ve kısa notları, İngilizce ve Türkçe.

| Klasör | İçerik |
| --- | --- |
| `figures/overview/` | Genel bakış şekilleri (motor kesiti ve tasarım kapsamı, güç yolu, pal ucu hızı, tork zinciri, fazlar ve gözden geçirmeler, gereksinim durumu, uyum, test sırası, kütle geçmişi; `make_figs.py` çizer) ve montaj ile taşıyıcı resimlerinin görüntüleri |
| `figures/phases/en`, `figures/phases/tr` | Her fazın analiz şekilleri (`p0_` – `p3_` önekleri) |
| `figures/step36` … `figures/step312` | Faz 3 analizlerinin şekilleri; `calc/` ve `comparison/` araçları yazar |
| `notes/` | Her faz için ana sayıları ve kararları veren birer sayfa |
